# Machine Learning Project

Proyecto de Machine Learning para la etapa P1 (problema, dataset y EDA) del curso.

## Dataset
- `WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Objetivo
Analizar y comprender el problema de churn de clientes de telecomunicaciones, identificando factores asociados a la deserción y preparando la base para el modelado predictivo en etapas posteriores.

## Notebooks
- `notebooks/01_eda_telco_churn.ipynb`: formulación del problema, descripción del dataset y análisis exploratorio de datos (EDA).

## Documento escrito (P1)
- `paper/P1_Telco_Churn_Analysis.pdf`: versión escrita del proyecto P1 en formato de artículo académico breve, conforme a la guía del curso.

## Requisitos
- Python 3.10+
- Jupyter Notebook / JupyterLab
- pandas, numpy, matplotlib, seaborn

## Ejecución
1. Abrir el notebook en Jupyter.
2. Ejecutar todas las celdas en orden.
3. Revisar los gráficos y hallazgos del EDA para la entrega P1.
